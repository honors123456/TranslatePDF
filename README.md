# TranslationPDF

自用 PDF 翻译工具站：上传 PDF，接入 DeepSeek / Claude / Gemini 等自有 API Key 进行全文翻译，输出双语对照或纯译文 PDF，支持在线预览与下载。灵感来自[沉浸式翻译](https://app.immersivetranslate.com/)。

## 功能

- 上传 PDF，保留原排版翻译（基于 [pdf2zh-next](https://github.com/PDFMathTranslate/PDFMathTranslate-next) / [BabelDOC](https://github.com/funstory-ai/BabelDOC)）
- BYOK：使用自己的 API Key，Key 只存浏览器本地
- 双语对照 / 纯译文两种输出
- 翻译进度实时显示，完成后在线预览、下载
